# 2.8-inch Sunton CYD

The **Sunton ESP32-2432S028R**, better known as the **Cheap Yellow Display (CYD)**, is the most affordable way to run EspControl — often under £10. It pairs a plain **ESP32** (no PSRAM, 4MB flash) with a 2.8-inch 320×240 resistive touchscreen, so this port trades a few features for a tiny price.

## Specifications

| | |
|---|---|
| **Screen size** | 2.8 inches |
| **Resolution** | 320 × 240 |
| **Orientation** | Landscape |
| **Display interface** | SPI (ST7789 / ILI9341) |
| **Processor** | ESP32 (no PSRAM) |
| **WiFi** | Built-in (2.4 GHz) |
| **Flash** | 4MB |
| **Touch** | XPT2046 resistive |
| **Power** | Micro-USB / USB-C |

::: warning Board revisions
The default firmware targets the **dual-USB revision** (micro-USB + USB-C side by side), which uses an ST7789 panel with inverted colors. The original single micro-USB revision uses an ILI9341 panel instead — if your colors look inverted, build with `cyd_display_model: "ILI9341"` and `cyd_display_invert: "false"` (see the manual setup below).
:::

## What's different on this panel

The CYD has a fraction of the memory of the other supported screens, so this port makes some deliberate trade-offs:

- **4 cards per page** in a 2×2 grid, with **left/right arrows** beside the clock to flip between the main page and your subpages like a carousel.
- **Web Setup Mode**: the configuration web UI only runs while setup mode is on (it starts automatically on a freshly flashed panel). Toggle it from Home Assistant (*Web Setup Mode* switch) when you want to rearrange cards; turning it off returns the RAM to the panel.
- **No camera/image cards and no album art** — decoding images needs PSRAM this board doesn't have. The media card and the now-playing screensaver still work, showing track titles as text.
- **English UI only** and a single icon size, to fit the 4MB flash alongside OTA updates.

Bonus hardware exposed to Home Assistant: the rear **RGB status LED** as a light, and the front **light sensor** as an illuminance-style sensor.

## ESPHome Manual Setup

If you use ESPHome and prefer to compile firmware yourself:

```yaml
substitutions:
  name: "kitchen-cyd"
  friendly_name: "Kitchen CYD"
  # Uncomment for the original single micro-USB revision:
  # cyd_display_model: "ILI9341"
  # cyd_display_invert: "false"

wifi:
  ssid: !secret wifi_ssid
  password: !secret wifi_password

packages:
  setup:
    url: https://github.com/tcbutler/espcontrol/
    ref: cyd-support
    file: devices/sunton-esp32-2432s028r/packages.yaml
    refresh: 1sec
```
